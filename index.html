Why does this matter for computation? +

A formal rule states a condition and an operation. Modern programs can represent selected grammatical rules this way. This is a comparison of methods, not a claim that Pāṇini invented computers or modern programming.

03 / 07 · THE MEETING OF VOWELS

Two sounds.
A transformation.

Sandhi means joining. Svara Sandhi concerns changes where vowel sounds meet under the relevant grammatical conditions.

VOWEL LEVEL · GUṆA

अ + इ → ए

WHOLE-WORD EXAMPLE

तव + इदम् → तवेदम्

tava + idam → tavedam

In तव, the final a is inherent in व. A program must work with sounds, not blindly replace the last written character.

From rule
to result.

A condition. An operation. An explanation.
Follow one example through the program.

STEP 1 OF 5
See the demo’s actual decision order +
normalize and validate independent vowels
if protected dual ending ī/ū/e: Prakṛtibhāva (unchanged)
else if prefix a/ā + root e/o: Pararūpa
else if word-final e/o + short a: Pūrvarūpa
else if same a/i/u class: Dīrgha
else if a/ā + i/ī or u/ū: Guṇa
else if a/ā + e/ai or o/au: Vṛddhi
else if i/ī or u/ū + dissimilar vowel: Yaṇ
else if e/ai/o/au + vowel AND internal: Ayādi
else: explain that input is unsupported

This is the order of this limited teaching engine, not a claim about the full Pāṇinian rule-ordering system. Guided words are stored examples, not outputs of a general word parser.

A rule-based system does not require machine learning.

Content decisions & scope +

All eight categories from the reference images are taught: Dīrgha, Guṇa, Vṛddhi, Yaṇ, Ayādi, Pūrvarūpa, Pararūpa and Prakṛtibhāva. Prakṛtibhāva means preservation without a Sandhi change. Category counts vary by teaching scheme.

Word examples have been replaced with directly checkable traditional illustrations. Ayādi is explicitly a stem-level demonstration. The engine excludes ṛ/ḷ and context-dependent external Ayādi outputs rather than giving an overconfident result.

The visual letters use correctly shaped HTML in CSS 3D space. This keeps the complete lesson available without WebGL, a GPU-heavy scene or a separate 3D download.
